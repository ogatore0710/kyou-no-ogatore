# 相談室 返答パターン下書き（目的・お悩み系）

調査+下書きのみ。**index.html / soudan-kb.js は未編集**。本体反映は別エージェント担当。

## 0. 事前調査サマリ（実装担当への申し送り）

- 相談室エンジン本体は `index.html` 内の `sd*` 関数群（`sdSend`/`sdIntentById`/`sdRenderChips`/`sdPush` 等、行3000〜3200付近）。KBデータは別ファイル `soudan-kb.js`（`SOUDAN_KB.intents[]` / `redFlags` / `commonFollowups` / `smalltalk`、契約コメントはファイル先頭に明記）。
- **想定より遥かにKBが充実済み**: `soudan-kb.js` は現在 **126インテント**あり、依頼文にあった例（猫背/反り腰/デスクワーク/運動不足/スポーツ前後ケア/産後）は**ほぼ全部すでに既存インテントとして存在**していた（`nekoze`, `sorigoshi`, `nekosori`, `swayback`, `deskwork`, `zenshin`, `undomae`, `undogo`, `running`, `golf`, `dakko`, `nyoumore`, `pokkori`, `yasetai`, `hipup`, `ninoude`, `haminiku`, `kogao`, `mukumi` など）。
- 動画タグ体系は `videos.js` の `tags` フィールドで確認（依頼文の「目的」タグと一致）: `むくみ`(18) `引き締め`(168) `筋膜・マッサージ`(15) `スポーツ・運動前後`(14) `生活・セルフケア`(7)。他に頻出タグとして `姿勢・背中`(48) `太もも・お尻`(89) 等もあり。
- そのため本下書きは「新規インテントを丸ごと80個作る」のではなく、**既存インテントに紐づく言い回しバリエーション（kw拡充候補）＋その言い回しに対する自然な返答文言案**として整理した。表中「マップ先」列に既存intent idを明記。既存が無い/薄い切り口（産後の体形・引き締め全般の入口・生活習慣の入口など）は新規文言案として書いた。
- トーン確認: `soudan-kb.js`実データを精読して踏襲。empathy行は句点なし短文が多い（例:「肩と首、ずっと重いのはつらいよねえ」）、mitateは原因説明→やさしい断定（〜だよ/〜なんだ）→最後に「！」で締め、keizokuは継続を後押しする一言。絵文字は多用しない（intents本文にはほぼ無し、smalltalkのみ😊等使用）。断定的な体形評価はしない（「〜かも」「〜のことが多いよ」等のヘッジを既存KBも徹底）。産後は redFlags.stateKw が「産後1ヶ月」等の具体的時期語を最優先で拾う設計なので、本下書きの産後カテゴリは**時期を明言しない一般的な体形・体調の相談**を想定して書いた（時期が出た発言は既存の状態系フローが先に処理する）。
