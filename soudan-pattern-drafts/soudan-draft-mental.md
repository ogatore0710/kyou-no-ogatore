## 4. 不安な気持ち → 新規インテント案（id: `fuan`・要注意枠）

> ⚠️ **本タスクの境界線を厳守**: これは「なんとなく落ち着かない」程度の**軽い日常的な不安**専用。
> 希死念慮（死にたい等）は`crisis`が最優先で拾うため、このkwには一切含めていない。
> 動悸・胸が苦しい・過呼吸・冷や汗などの身体症状は`redFlags`が既に拾うため、このkwにも一切含めていない
> （＝パニック発作や心疾患が疑われる訴えは、このインテントより先に既存の安全機構が受け止める設計を壊さないようkwを選定した）。

**共感**: 理由がはっきりしない不安、そわそわするよね。

**続け方**: 深呼吸しながらの1本を、そわそわする夜のお守りに。無理に「考えるのをやめよう」としなくて大丈夫だよ！

## 5. 頭がぼーっとする → 既存 `shakitto` へのkw追加（新規インテント不要）

**現状のchip/empathy/mitate/videos/keizoku/followups/safetyは変更不要**。すでに「眠気」「集中できない」「頭をすっきり」をカバーしており、mitate（「眠気やぼんやりの一因は、同じ姿勢で血流が滞ること」）はそのまま「頭がぼーっとする」の説明として使える。

```
あたまがぼーっと
あたまがぼんやり
ぼーっとする
ぼんやりする
しこうがまとまらない
あたまがはたらかない
しゅうちゅうりょくがつづかない
あたまにきりがかかった
のうがつかれた
あたまがすっきりしない
かんがえがまとまらない
あたまがおもだるい
```

**重複チェック**: 既存kw全件とexact match突合し重複なし。「しゅうちゅうできない」は既存`shakitto`のkwにすでにあるため重複させていない（含めていない）。

**設計理由・懸念点**:
- `shakitto`は現状`safety:false`。今回追加する「ぼーっとする」「あたまがぼんやり」系の語は、日中の眠気や集中力低下という軽い文脈なら`safety:false`のままで問題ないはずだが、まれに「急に頭がぼーっとする」がろれつが回らない・体の片側に力が入らない等の脳血管系サインの前触れとして使われる可能性はゼロではない。ただし、現状の`redFlags.kw`には「めまい」「眩暈」はあっても「ぼーっとする」「confusion」系の語は含まれていない。
  - 本タスクの指示どおり、こうした深刻なケースの判定は既存のredFlags/crisis設計に委ねる前提で、今回のkw追加自体は安全と判断した（`shakitto`が拾っても、実際の緊急サインは別の語＝しびれ・力が入らない等でredFlagsが先に拾う設計のはず）。
  - ただし、`shakitto`のmitateには受診導線が一切ないため、「ぼーっとする」という訴えを拾うインテントとして受診導線を追加すべきか（＝safety:trueに格上げすべきか）は、本人判断が必要な論点として明記しておく。今回のドラフトでは**現状維持（safety:false・mitate変更なし）**を提案するが、要検討事項として残す。
