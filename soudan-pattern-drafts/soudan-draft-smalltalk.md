## 0. 調査サマリー

### データ契約（ファイル冒頭コメント L14 より）
```
smalltalk[]: { kw:[...], replies:[2-3パターン。エンジンが日付ハッシュで選ぶ] }
```
`intents`と違い `empathy`/`mitate`/`videos`/`keizoku` の4点構成ではなく、**kw配列 + 返信2〜3パターンのみ**のシンプルな形。マッチ優先順位は `crisis → redFlags → intents(スコアリング) → smalltalk → フォールバック`（`TASK-C2-2026-07-31-soudan-quality-drafts.md`より）。intentsのスコアリングで拾われなかった入力が最後にsmalltalkでチェックされる想定。

`scripts/qa.js`（L1669-1670）のsmalltalk検証は非常にシンプルで、各要素が `kw`（非空配列）と `replies`（非空配列）を持っていることのみをチェック。intentsのような「kw重複禁止」チェックはsmalltalkには掛かっていない（コード上は`intents`ループ内のみ）。とはいえ質を保つため、下書きでは既存53件・新規ドラフトとも重複しないよう手動でチェック済み。

### 既存カバレッジ（53件、L1706-1977）
大きく3グループ:
1. **定番の挨拶・感情語**: おはよう/こんにちは/こんばんは/おやすみ、ありがとう、つかれた、応援して、すごいね、できた、楽しい、がんばる、だいすき、はじめまして、ひさしぶり、げんき/げんきない、まあまあ 等
2. **雑談トピック（オガトレの人となり）**: オガトレって誰、年齢、ホヤぼーや、気仙沼、好きな食べ物/趣味/色/季節/苦手なもの/飲み物/動物、得意技 等。天気（雨/暑い/寒い、晴れ）、週末、今日何してた、何食べた、おやつ、眠い、季節の変わり目、体に気をつけてね 等
3. **私生活のかわし（本人依頼で明確に用意された枠）**: 結婚してる/彼女彼氏いる/本名/身長体重/年収/住んでる場所/兄弟家族/LINE教えて/好きなタイプ ― いずれも「秘密にする」トーンで統一しつつ体づくりの話に軽く戻す構成。

### トーン確認（絵文字の扱い）
既存53件を全件読んだ結果、**絵文字は使われている**（intents側の`empathy`/`mitate`等ではおそらく控えめ、と別ドラフトで報告されているのと対照的に、smalltalkは実データで頻出）。具体的な使用パターン:
- ほぼ全ての1つ目のreplyが文末に`😊`で締める（例: L1708「朝いちの体はいちばん硬い。だからこそ効くんだよね😊」）。
- 2つ目のreplyは絵文字なしで「！」で軽く締めることが多い（例: L1709「今日も一日、いい姿勢でいこう！」）。
- 例外: 「つかれた」(L1731-1735)は両方とも絵文字なし＝重めの感情語には絵文字を控える傾向あり。「げんきない」(L1841-1845)は逆に1つ目に😊あり、一貫はしていないが「重い話題は絵文字控えめ」の傾向は感じ取れる。
- 絵文字は`😊`一種類のみで統一（他の絵文字は未使用）。
- 口調は「〜だよ」「〜だね」「〜よね」の親しみやすい話し言葉、一人称「僕」、たまに「!笑」（私生活かわし枠のみ）。説教臭さ・体育会系の圧はゼロ。

この下書きも上記に合わせ、**1つ目のreplyは基本😊で締め、2つ目は絵文字なしで！締め**、重めの話題（不眠・叱られた等）は絵文字を控える方針で書いた。

## 2. 実装時の注意点（申し送り）

1. **絵文字は`😊`のみに統一**し、1つ目のreplyの文末に置く運用を踏襲した。重い話題（#12眠れない, #18仕事やばい, #19学校しんどい, #20叱られた）は既存の「つかれた」に倣い絵文字を意図的に外した。

4. **#12「眠れない」**は安全域・慢性不眠の訴えとの切り分けに注意。深刻な訴え（「何日も眠れない」「不安で眠れない」等）は本来intents/redFlags側で拾うべきで、smalltalk#12は「今夜ちょっと眠れない」程度の軽い一言を想定した文言にとどめた。
